title: RFCs
---

An RFC is a design proposal for a Buck2 feature. It records what was proposed,
and why, when it was written.

RFCs are not updated when the feature changes, so an RFC can differ from how
Buck2 works today. Read them for the reasoning behind a design, and the rest of
this documentation for how to use it.

- **Implemented** has the proposals for features that Buck2 now has.
- **Drafts** has proposals that are not implemented, or are not implemented as
  proposed.
- The remaining proposals are listed on their own.
